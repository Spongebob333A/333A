# 改造记录

## 2.0.0 — 药时安心期末项目版

基于 `jiantous/anfu-pill-reminder` 二次开发。

### 新增或改造

- 从双端协同设想改为单手机模式；家属仅作为短信联系人。
- 新增短信联系人配置、短信权限申请和隐私开关。
- 新增未确认服药的 15/30 分钟分级处理。
- 新增低库存短信与“补货前只发送一次”的去重逻辑。
- 保留并接入暂停/恢复用药功能。
- 新增最近 7 天记录页。
- OCR 说明书识别改为“预填后人工确认”的业务规则。
- 排程界面限制为每日和每周指定日期。

### 删除或隐藏

- 删除 CSV 导出、JSON 备份与恢复、FileProvider 相关实现。
- 删除统计图表、月历与 30/90 天记录入口。
- 隐藏复杂间隔与周期排程入口。
- 不增加账号、二维码绑定、云同步、家属 App、定位、聊天或医疗建议。

### 文档

- 新增项目范围、实现说明和验收测试清单。
- 保留原项目 MIT 许可证并在 README 中注明来源。
