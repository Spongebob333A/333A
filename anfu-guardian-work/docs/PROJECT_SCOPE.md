# 项目范围：药时安心

## 1. 项目目标

帮助老人按既定计划服药，并让家属能够在家属端完成药品设置、观察服药反馈和关注库存提醒。当前交付为单设备前端演示版本；两种角色共享本机数据，跨设备协作留给后续 Spring Boot 后端实现。

## 2. 角色和职责

| 角色 | 当前端内可做的事 |
| --- | --- |
| 老人 | 查看今日服药、确认已服用、稍后提醒、跳过、查看近期记录、启用大字版 |
| 家属 | OCR 或手动添加药品，核对药品信息，设置计划与库存，暂停/恢复药品，查看服药记录，设置短信联系人 |
| Android 系统 | 提供相机、闹钟、通知及短信能力 |

角色入口仅作为本机演示，不代表已实现账号身份、二维码绑定或权限隔离。

## 3. 核心功能范围

### 3.1 家属端药品方案

- 手动录入或拍摄说明书，由本机 OCR 预填药名、剂量、频次和用药要求；识别内容须人工核对。
- 单位提供“片、粒、袋、瓶、ml、自定义”；开始和结束日期通过日历选取。
- 支持每日或每周计划、多个提醒时刻、服药要求、库存和低库存阈值。
- 可暂停至指定日期并恢复；也可归档或删除药品。

### 3.2 风险预检

- 保存前提示可能的资料问题，例如药品重名或备注中已有相互作用提示，并要求家属再次确认。
- 当前规则不是 AI，也不替代药物相互作用核验；如要实现真正的风险分析，需要接入经审核的数据源或服务，并补充来源、更新时间及风险解释。

### 3.3 老人端服药

- 展示今天的计划、时间、单次剂量和餐前/餐后要求。
- 提供“已服用”“稍后提醒”“跳过”操作。
- 大字模式以放大文字为主，保持卡片和图标尺寸，利用自动换行保持窄屏可读。

### 3.4 记录、库存与预警

- 每次服药结果形成本地记录；只有标记“已服用”才按剂量扣减库存。
- “稍后提醒”“跳过”和尚未确认不扣库存。
- 库存到达阈值时展示本机补药提示；长时间未确认时触发本机提醒，并可尝试向已配置联系人发送短信。
- 可查看最近服药记录。

## 4. 暂不纳入本次交付

- Spring Boot API、云端数据库、用户注册、二维码绑定、跨设备数据同步；
- 家属手机实时接收老人端状态变化；
- 接入真实 AI 或权威药品相互作用知识库；
- 通过服务器发送短信或推送消息。

因此，本地同设备上的角色切换、记录和库存流程可演示，但不能据此宣称已经完成真正的老人—家属跨手机协作。

## 5. 数据与安全边界

药品和记录保存在 Android 应用私有目录。短信正文应尽量减少健康信息；短信发送成功与否由系统服务结果决定。系统仅承担提醒与记录功能，不判断是否应当开始、停止或调整处方药。
