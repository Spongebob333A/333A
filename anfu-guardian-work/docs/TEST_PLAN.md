# 验收场景清单

以下为建议的手动验收场景；本次改动尚未在设备上逐项实测。

| 编号 | 场景 | 操作 | 预期结果 |
| --- | --- | --- | --- |
| R1 | 角色入口 | 冷启动应用 | 显示老人端、家属端选择；选择后打开对应首页 |
| R2 | 老人端操作 | 在老人端查看今日列表并标记已服用、稍后提醒或跳过 | 按钮文字明确；已服用记录时间并扣库存，稍后提醒及跳过不扣库存 |
| R3 | 老人端权限 | 尝试从老人端进入药品编辑 | 老人端不显示添加药品入口，药品方案由家属端维护 |
| R4 | 家属录入 | 手动添加药品，选择单位、时间和日期 | 表单保存正确，提醒重新安排 |
| R5 | OCR | 拍摄含药品信息的说明书 | 识别内容只预填表单，未经人工保存确认不会写入药品 |
| R6 | 风险复核 | 保存同名药品或备注中含风险提示的药品 | 显示预检结果；家属可返回修改或二次确认；说明不会误导为医学结论 |
| R7 | 暂停恢复 | 暂停药品至指定日期并恢复 | 暂停期间无提醒；恢复后按原计划重新安排 |
| R8 | 库存不足 | 设置库存与阈值，确认服用至阈值 | 库存按剂量扣减，出现本机库存提醒；短信仅在联系人、权限和设备条件满足时尝试发送 |
| R9 | 未确认服药 | 到达计划时间后不操作 | 本机重复提醒；联系人短信提醒的是“请核实”，不能称为已确认漏服 |
| R10 | 大字模式 | 老人端打开大字版，查看今日列表、按钮和记录 | 文字清晰，窄屏卡片及操作按钮可换行，主要操作不被遮挡 |
| R11 | 记录 | 在记录页查看近期服药情况 | 显示实际服用、跳过和未确认状态及相应时间 |
| R12 | 后端边界 | 在另一台设备上切换家属端并尝试同步 | 当前版本没有账号和后端，数据不会跨手机同步 |

建议在 Android 真机和模拟器分别核对通知权限、精确闹钟、相机 OCR、短信授权和大字版布局。
